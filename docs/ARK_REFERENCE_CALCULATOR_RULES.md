# Calculator rules — correct implementation and safety checks

1. **Breeding:** Egg incubation ≈ base minutes / `EggHatchSpeedMultiplier`, mammal pregnancy using the appropriate supported breeding multiplier (confirm in-game for special creatures). Maturation ≈ base minutes / `BabyMatureSpeedMultiplier`; 10% baby, 40% juvenile, 50% adolescent; minute-precision can drift. Exclude `timer_usable=false` or `asa_availability` that starts `Not in unmodded ASA`. No Rhyniognatha/Reaper generic countdown.
2. **Mutation:** Base any-mutation probability `1-(1-0.025)**3` when BOTH parents below 20 on each applicable mutation counter. For `p_target`, required independent births `ceil(log(allowable_failure_rate)/log(1-p_target))`. p_target must reflect stat roll, inheritance preference, sex selection, traits and mutation-counter eligibility. Do not equate `p_any` and `p_target`.
3. **Raid:** For each distinct layer/target `ceil(effective_hp / effective_weapon_damage)`, then **sum** those layer counts. Apply structure-specific HP, attack restrictions, damage modifiers, explosive falloff, server settings and target-specific special defenses. Do not simply multiply a total by the number of layers and divide as though all layers were homogeneous.
4. **Tranq:** Base torpor/shot values assume 100% weapon quality and ordinary conditions. Species damage resistance, weapon effectiveness, shot interval, torpor-over-time and target torpor depletion all influence actual count. Treat `ceil(torpor_remaining / expected_torpor_per_hit)` as a lower-order estimate. Don't promise exact rounds unless verified creature modifiers and temporal model present.
5. **Boss checklists:** Use only individually separated tier rows. Do not generate fake element amounts or tribute lists for combined/unknown tiers. Keep `null` as unknown, not zero.
6. **EP:** Total EP from level table less *selected unlocked* engrams; Engram points are not XP. Check if character has bonus levels, DLC engrams and respec history.
7. **INI:** Group exact file/header; generate only supported keys for selected server version. Validate booleans/integers/positive multipliers, quote paths, and never expose admin passwords in shared text exports.
8. **All calculators:** User server settings, individual session mods, game version and event boosts supersede baseline 1x assumptions.
